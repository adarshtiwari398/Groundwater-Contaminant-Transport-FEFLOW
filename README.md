# Contaminant Transport Modelling in Groundwater Using FEFLOW

## Overview

This repository contains my M.Tech project on groundwater contaminant transport modelling using FEFLOW and ArcGIS. The study focuses on analysing groundwater flow and iron contamination around the Boragaon Dumpsite, Guwahati, Assam.

## Objectives

- Simulate groundwater flow.
- Model iron contaminant transport.
- Identify contamination hotspots.
- Support groundwater quality assessment.

## Tools Used

- FEFLOW
- ArcGIS
- Microsoft Excel

## Study Area

Boragaon Dumpsite, Guwahati, Assam, India.
